# EP-02 · The team keeps the plant catalogue right
Goal: the care advice people get comes from a catalogue the team keeps up to date.

## REQ-10 · See the state of the catalogue
- Status: ready
- Priority: should
- Screens: AD-01

As a catalogue editor, I want to see how many plants lack care advice, so that I know where to start.

Acceptance criteria
- Given 12 plants have no watering interval, when I open the dashboard, then I see "12 without an interval" with a link to them.

## REQ-11 · Edit a plant in the catalogue
- Status: draft
- Priority: should
- Screens: AD-02

As a catalogue editor, I want to change a plant's care advice, so that every owner of that plant gets the new advice.

Rules
- A change applies to new reminders only; reminders already set stay as they are.
