# raw — put everything you have here

Drop in all the material you have for this project, as it is, without sorting it: an existing site or app (files, a zip, screenshots, links in a text file), brand book, logo, fonts, photos, texts and copy, requirements or backlog exports, notes from meetings, research, reviews, examples you like or dislike. Subfolders and any names are fine.

Then run `/orbito-init` in Claude Code. Orbito goes through this folder, tells you what it found and how good it is, and after you agree, copies what is needed to the right places in the project (requirements, content, design system, pictures). This folder stays as you left it: it is the original that everything else is traced back to.

Client and personal data: this folder is left out of git by default (`.gitignore`), so nothing here is shared by accident. Orbito never copies personal data, real client names or prices into anything that is exported or published without asking you first.
